\# Student Performance Data Analysis



\## Project Overview

This project uses Python to analyze a sample student performance dataset. It uses Pandas for data analysis and Matplotlib for visualization.



\## Features

\- Load data from a CSV file

\- Display the first five records

\- Calculate descriptive statistics and subject averages

\- Identify missing values

\- Create a bar chart of average subject marks

\- Create a scatter plot of study hours versus mathematics marks

\- Create a correlation heatmap

\- Generate observations from the analysis



\## Technologies Used

\- Python 3.13

\- Pandas

\- Matplotlib



\## Dataset

The project uses an illustrative dataset containing 15 sample student records. The columns include study hours, attendance percentage, and marks in Mathematics, Science, and English.



The data is for demonstration purposes and does not represent actual student records.



\## How to Run

1\. Install Python.

2\. Install the dependencies with `python -m pip install pandas matplotlib`.

3\. Ensure `dataset.csv` is in the same folder as `data\_analysis.py`.

4\. Run `python data\_analysis.py`.



\## Output

The program displays statistical summaries, average marks, and observations. It saves three visualizations in the `visualizations` folder:

\- `bar\_chart.png`

\- `scatter\_plot.png`

\- `heatmap.png`



\## Conclusion

The sample data shows that English has the highest average marks, while Mathematics has the lowest. Study hours and Mathematics marks have a strong positive correlation in this sample. Correlation does not establish causation.
